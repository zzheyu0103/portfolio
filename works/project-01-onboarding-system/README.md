# Project 01｜卡牌對戰遊戲的新手教學與七日任務系統設計

## 專案目標

把「新手第三天後流失」這個問題，整理成一份可以拿去面試、也可以真的往下做的遊戲企劃作品。

## 你要做出的東西

1. `player-journey.md`
   新手前七天的玩家旅程與痛點分析
2. `mission-plan.csv`
   七日任務表與獎勵節奏
3. `wireframe-spec.md`
   四個核心畫面的內容規格
4. `interview-script.md`
   面試時可直接講的精簡版

## 建議完成順序

1. 先看 `player-journey.md`
2. 再填 `mission-plan.csv`
3. 依照 `wireframe-spec.md` 畫 Figma 線框
4. 最後把重點濃縮到 `interview-script.md`

## 最後應該長成什麼

- 一份 3 到 5 頁的企劃案例
- 一張完整七日任務表
- 4 張 Wireframe
- 一段 2 到 3 分鐘口頭說法
