# Project 01｜卡牌對戰遊戲的新手教學與七日任務系統設計

## 專案目標

這個專案以「新手在第三天後逐漸流失」為題，重新整理卡牌遊戲前七天的引導節奏、任務安排與成長回饋，並做成可操作的多頁流程原型。

## 內容組成

1. `player-journey.md`
   新手前七天的玩家旅程與痛點分析
2. `mission-plan.csv`
   七日任務表與獎勵節奏
3. `wireframe-spec.md`
   四個核心畫面的內容規格
4. `interview-script.md`
   專案摘要與簡報用版本

## 建議閱讀順序

1. 先看 `player-journey.md`
2. 再填 `mission-plan.csv`
3. 依照 `wireframe-spec.md` 畫 Figma 線框
4. 最後把重點濃縮到 `interview-script.md`

## 目前交付內容

- 一份完整的設計案例說明
- 一張完整七日任務表
- 4 張 Wireframe
- 一份可搭配簡報使用的專案摘要
