# 作品區

這裡放的是作品內容本體，不是網站程式。現在每個題目都已經整理成一個真正可開工的專案資料夾。

## 專案列表

- `project-01-onboarding-system/`
  新手教學、玩家旅程、七日任務表、Wireframe 規格、面試講稿
- `project-02-retention-analysis/`
  分析簡報、假資料、SQL 查詢、Python/R 腳本、儀表板規格
- `project-03-event-ops-dashboard/`
  活動企劃、獎勵經濟表、活動時程、Python KPI 腳本、pandas 工作簿、正式報告、儀表板規格

## 對應網站展示頁

- `site/project1/index.html`
  主打的多頁遊戲流程 prototype
- `site/project2/index.html`
  留存分析與玩家分群展示頁
- `site/project3/index.html`
  節慶活動與 Live Ops KPI 展示頁

## 建議工作方式

1. 先完成 `project-01-onboarding-system/`
2. 再做 `project-02-retention-analysis/`
3. 最後補 `project-03-event-ops-dashboard/`

## 你下一步最適合做什麼

- `project-01-onboarding-system/wireframe-spec.md`
  依照這份規格去 Figma 畫 4 張畫面
- `project-02-retention-analysis/mock-data/player_events.csv`
  用 Sheets、Excel 或 Python 開始分析
- `project-02-retention-analysis/python/retention_analysis.py`
  直接跑出 cohort、segment 與 churn signal
- `project-03-event-ops-dashboard/economy-table.csv`
  先把獎勵和活動幣平衡調順
- `project-03-event-ops-dashboard/python/liveops_kpi_simulator.py`
  練習把活動 KPI 與經濟表串成營運摘要
- `project-03-event-ops-dashboard/python/liveops_kpi_pandas.py`
  產出 Excel、PNG 圖與更正式的 Live Ops 分析交付物
