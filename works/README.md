# 作品區

這裡放的是各專案的原始資料與文件，不是網站前台頁面。每個題目都整理成獨立資料夾，後續補內容或延伸都比較方便。

## 專案列表

- `project-01-onboarding-system/`
  新手流程、玩家旅程、七日任務表、線框規格與專案整理
- `project-02-retention-analysis/`
  分析說明、假資料、SQL 查詢、Python/R 腳本與儀表板規格
- `project-03-event-ops-dashboard/`
  活動設計、獎勵經濟表、活動時程、Python KPI 腳本、pandas 工作簿與正式報告

## 對應網站頁面

- `site/project1/index.html`
  主打的多頁遊戲流程原型
- `site/project2/index.html`
  留存分析與玩家分群展示頁
- `site/project3/index.html`
  節慶活動與 Live Ops KPI 展示頁
