# 分析簡報草稿

## 問題情境

一款休閒消除手遊近期廣告導量穩定，D1 留存正常，但 D7 留存比上月下降 11%。

## 主要問題

1. 是哪一群玩家先流失？
2. 流失前集中發生了哪些事件？
3. 問題比較像關卡、活動還是新手引導？

## 分析步驟

1. 先確認流量來源與裝置分布是否有顯著變化
2. 切出新玩家 cohort
3. 觀察 D1 到 D7 的登入與關卡事件
4. 切分卡關玩家、低活躍玩家、付費玩家
5. 提出 2 到 3 個主要假設

## 假設範例

- 假設 A：第 8 關難度過高，造成第三天後大量流失
- 假設 B：新手活動在第二天結束，玩家失去短期目標
- 假設 C：低活躍玩家沒有被有效召回
